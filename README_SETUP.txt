🚀 QUICK START

1. View the Website
   → Open http://localhost:3000 in your browser
   → Click "Open Invitation" to start
   → Scroll through all 10 sections

2. Customize Couple Names (2 minutes)
   → Edit src/config/weddingData.ts
   → Change brideName, groomName, weddingDate, destination
   → Page automatically updates

3. Add Your Photos (5 minutes)
   → Update image URLs in src/config/weddingData.ts
   → Gallery section will show your images

4. Change Colors (2 minutes)
   → Edit app/globals.css color variables
   → All colors update site-wide

❓ COMMON QUESTIONS

Q: How do I change the couple names?
A: Edit src/config/weddingData.ts - brideName and groomName

Q: How do I add my wedding photos?
A: Update the image URLs in src/config/weddingData.ts gallery array

Q: How do I change the colors?
A: Edit the :root CSS variables in app/globals.css

Q: Does the RSVP form save data?
A: Currently in demo mode. To save, connect a backend database.

Q: Is it mobile-friendly?
A: Yes! Fully responsive from 360px width to desktop.

Q: Can I host this myself?
A: Yes! Build with npm run build, then use npm run start or Docker.
